# Interface screenshots

Captured from the OpenUninstaller 1.0.6 Release views on Windows, 31 October 2026.
Each screen has `-dark.png` and `-light.png` variants. The main window is 1440 × 860;
the Hunter action dialog uses its natural size.

Program inventories, startup entries, package metadata, file paths, cache counts and backup
history are sample data supplied in memory to the actual application view models. They do
not represent the capturing machine's inventory or completed cleanup operations. Built-in
Windows tools and application controls come from the release source.

The capture process did not uninstall programs, clean caches, shred files or restore backups.
The README selects the matching image for the reader's preferred color scheme.
