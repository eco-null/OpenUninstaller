## Hunter mode: correct application ownership

OpenUninstaller 1.0.6 fixes incorrect application names and uninstall targets in Hunter mode.
For example, selecting an OpenUninstaller window could previously identify it as OpenCode
because both names contained the publisher fragment `Open`.

### What's changed

- Hunter uses executable-path evidence instead of application-name or publisher guesses.
- Exact executable matches take priority; nested installations use the most specific directory.
- Equally strong conflicting owners remain unmatched. Identical shared HKCU registry views
  are recognized as one owner, without merging separate installations.
- Environment-variable paths are normalized; relative paths and root install locations are rejected.
- The README includes new light/dark screenshots of all eight screens and Hunter mode.
  Screenshots use sample data rendered by the actual application views.
