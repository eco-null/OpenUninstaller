# Plan 06 — Desktop UI

Status: **implemented in v0.1; autorun search and service/task rows added in v0.3; queue, ignore/diff and restore preview added in v0.4; privacy/shredder page, telemetry and service settings added in v0.5**

## Shell

```
┌──────────────────────────────────────────────────────────────────────┐
│ OpenUninstaller          [search]                 [admin] [refresh]  │
├──────────────┬───────────────────────────────────────────────────────┤
│  Programs    │  Content (page per navigation item)                  │
│  Autoruns    │                                                       │
│  Junk files  │                                                       │
│  Privacy     │                                                       │
│  Backups     │                                                       │
│  Windows     │                                                       │
│  Settings    │                                                       │
├──────────────┴───────────────────────────────────────────────────────┤
│ status: 214 programs · 5 backups · last scan 12:04 · v0.5.0          │
└──────────────────────────────────────────────────────────────────────┘
```

- WPF, MVVM, no third-party UI library.
- Dark theme by default with a light theme toggle; accent `#4CC2FF`.
- Custom window chrome is avoided to keep accessibility, snapping and DPI simple; standard chrome
  with a themed content area.
- Fonts: Segoe UI Variable / Segoe UI fallback. All text scalable; no fixed pixel fonts.
- Keyboard: Ctrl+F focus search, F5 refresh, Esc closes dialogs, Enter confirms default button.

## Pages

### Programs

- Header with counts and an "Install with tracing" button.
- Search box (name, publisher, install location), architecture filter, sortable DataGrid:
  name (with icon), publisher, version, size, install date, architecture.
- Details panel: install location (clickable), uninstall command (read-only, monospace), registry
  path, help link, estimated size.
- Queue column with a checkbox; **Uninstall queued (N)** reviews each selected application in
  order, and **Clear** empties the queue.
- Actions: **Uninstall…**, **Forced uninstall…**, **Scan leftovers…**, **Export CSV/JSON**.
- Empty state with a refresh button; loading state with progress ring.

### Uninstall flow (modal workflow)

1. **Confirm**: app summary, exact command, "prefer silent uninstall" checkbox (disabled when no
   quiet command), backup toggle (on), "continue" danger button.
2. **Run**: step list with spinner per step (run uninstaller, verify, scan). Cancel is offered; a
   running vendor uninstaller is not force-killed (the step shows "waiting for the vendor
   uninstaller" and lets the user continue once it exits).
3. **Review**: grouped tree (Registry / Files) with checkbox, name, reason, confidence badge,
   protected items disabled. Summary bar: selected count and bytes. A previous-scan comparison shows
   new, resolved and unchanged candidates. **Ignore selected** hides items from later scans and
   **Reset ignored** restores them. Warning text: "Removing the wrong key can break other
   software." Deletion requires checkbox + confirm button.
4. **Result**: removed/skipped/failed counts, backup id with "Open backup" and "Restore", log path.

### Autoruns

Table with enabled toggle, name, command, source, publisher. Disable/enable confirms; a note
explains that entries are disabled reversibly and where they are stored.

### Junk files

Category cards with size/count and checkbox, scan button, "Clean selected" danger button with
confirmation, dry-run preview switch in settings. Recycle bin is a separate card with an explicit
"Empty recycle bin" action.

### Backups

List with date, program, item counts, completeness; details pane with manifest summary; Preview…,
Restore… and Delete backup… actions. Preview opens a read-only table of restore/overwrite/skip/
blocked targets. Restore shows an overwrite checkbox and per-item result.

### Settings

- Confirm destructive actions (always on, not disableable).
- Prefer silent uninstall by default.
- Back up before delete (on; turning off shows a warning).
- Backup retention count (default 20).
- Theme (dark/light/system).
- Trace location and backup location (read-only, open folder).
- About: version, license, "telemetry off by default" statement, link to docs.

## Dialogs

- `ConfirmDialog` (title, body, danger flag) and `ReviewDialog` for leftovers.
- All destructive dialogs use the danger button style and focus the safe action.
- Errors surface in an inline banner plus "copy details", not MessageBox chains.

## ViewModels

`MainViewModel`, `ProgramsViewModel`, `UninstallWorkflowViewModel`, `AutorunsViewModel`,
`JunkViewModel`, `BackupsViewModel`, `SettingsViewModel`, `HunterViewModel`.

- Commands: `AsyncRelayCommand` with `CanExecute`, cancellation, and re-entrancy guard.
- Services injected by constructor from `App.Composition`.
- No code-behind logic beyond window drag/close and the hunter overlay input.

## Accessibility

- AutomationProperties.Name on icon-only buttons.
- Focus visuals preserved; contrast ≥ 4.5:1 for body text.
- DataGrid supports keyboard navigation; row actions also in the details pane.
- Progress and results announced via status bar text.
