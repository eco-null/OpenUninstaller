## Broader discovery and safer cleanup

OpenUninstaller 1.0.8 expands Junk Files and leftover discovery while keeping uncertain
matches separate from files authorized for cleanup.

### What's changed

- Review individual junk files with paths, sizes and modification times; filter results, select
  files, cancel scans and see skipped/incomplete locations.
- Search selected folders or drives with filename masks and access-age filtering. Separate
  Include folders report regular files regardless of the main age, mask or exclusion filters.
- Inspect locked and hard-linked file metadata in reports without making those files cleanable.
- Discover deeper application-data leftovers using name boundaries and show Windows Installer
  identity references as protected, unselected suggestions.
- Revalidate file identity, timestamps and resolved paths before cleanup. Preserve browser offline
  storage and enforce leftover ownership/protection before backup or deletion.
- Improve shortcut, PATH, firewall and task matching; deduplicate overlapping scan roots/warnings
  and report traversal limits instead of silently claiming a complete scan.

Additional filename matches and uncertain ownership suggestions remain report-only. Existing
cleanup confirmations and deletion protections continue to apply.

Both packages target Windows 10/11 x64 and include the .NET runtime. Run `OpenUninstaller.exe`
from the portable archive; its CLI is `cli\oucli.exe`. The optional maintenance service is included
but is not installed automatically. Both downloads have accompanying `.sha256` files.

### Verification

- Release solution build with warnings treated as errors; 300 core/CLI tests.
- WPF Junk preview with 10,001 rows, protected selection checks, scope validation and virtualization.
- Both themes at 820/1220/1700 DIP; desktop smoke checks across all eight screens.
- Controlled report fixtures: 19 pattern matches / 202 bytes and 24 Include files / 296 bytes.

The fixtures validate expected application behavior; they do not establish identical output to
another scanner on a live machine.

These builds are unsigned. See the [security policy](https://github.com/eco-null/OpenUninstaller/blob/v1.0.8/SECURITY.md)
for distribution details.
