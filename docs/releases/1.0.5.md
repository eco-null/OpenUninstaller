## Desktop interface refresh

OpenUninstaller 1.0.5 updates the desktop interface and documentation while preserving the existing
uninstall, review, backup and confirmation workflows.

### What's changed

- Coordinated light and dark zinc themes with consistent controls and a cleaner navigation rail.
- Resizable application details; compact windows reclaim list space when no application is selected.
- Shorter, task-focused copy across all eight screens, with redundant workspace and footer labels removed.
- A refreshed application and installer icon with nine Windows icon sizes and an editable SVG source.
- An updated README with current screenshots, correct executable paths and clearer setup instructions.

### Downloads

- **Installer:** [OpenUninstaller-1.0.5-setup.exe](https://github.com/eco-null/OpenUninstaller/releases/download/v1.0.5/OpenUninstaller-1.0.5-setup.exe)
- **Portable:** [OpenUninstaller-1.0.5-win-x64.zip](https://github.com/eco-null/OpenUninstaller/releases/download/v1.0.5/OpenUninstaller-1.0.5-win-x64.zip)

Both packages target Windows 10/11 x64 and include the .NET runtime. The portable desktop executable
is `OpenUninstaller.exe`; the CLI is `cli\oucli.exe`. The optional maintenance service is included
but is not installed automatically. Matching `.sha256` files accompany both downloads.

### Verification

- Release build with warnings treated as errors.
- 167 core and CLI regression tests.
- Desktop UI smoke: eight screens, two themes and two window sizes, plus search and selection checks.

These builds are unsigned. See the [security policy](https://github.com/eco-null/OpenUninstaller/blob/v1.0.5/SECURITY.md)
for distribution details. Privacy cleanup and shredding remain irreversible; file restore retains
its documented local NTFS/TxF and permission requirements.
