## Improved layouts, startup management and sorting

OpenUninstaller 1.0.7 improves the desktop layout, expands startup discovery and adds
sorting controls to application and autorun lists.

### What's changed

- Settings and Privacy use centered, stable groups with two columns at standard and wide
  window sizes, and one column in narrow windows. Related settings are grouped together;
  long privacy lists scroll within their cards.
- Junk and Windows tools cards adapt to the available content width.
- Autoruns opens in Basic view for application startup entries. Advanced shows the complete
  inventory, while History & rollback remains available separately. Microsoft user
  applications remain visible in Basic; Windows system entries, kernel drivers and
  manual-only services are hidden there.
- Startup discovery includes packaged applications' declared startup tasks and scheduled
  tasks accessible through Task Scheduler. Windows-disabled Run and Startup-folder entries
  retain their current state. Packaged startup tasks are managed through Windows Startup settings.
- Programs, Autoruns, autorun history and Store apps have synchronized sort pickers and
  clickable column headers. Program sizes and install dates sort by their actual values;
  unknown values stay last, and reordering preserves selected and queued applications.

Both packages target Windows 10/11 x64 and include the .NET runtime. Run `OpenUninstaller.exe`
from the portable archive; its CLI is `cli\oucli.exe`. The optional maintenance service is included
but is not installed automatically. Both downloads have accompanying `.sha256` files.

- Desktop smoke checks across eight screens, both themes and standard/minimum window sizes.
- Settings and Privacy layout checks at four content widths, independent of screen resolution.
