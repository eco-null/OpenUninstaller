## More complete leftovers, faster scans and reliable uninstalls

OpenUninstaller 1.0.9 finds leftovers it previously skipped, scans about four times faster and
handles vendor uninstallers that relaunch themselves or are registered without quotes.

### What's changed

- **PATH cleanup in Program Files:** PATH entries inside an application's own Program Files folder
  (for example `C:\Program Files\Git\cmd`) are offered. The Windows folder, the Program Files roots
  and Common Files stay protected.
- **Product registry keys:** single-level keys such as `HKCU\Software\7-Zip` are offered when the
  name matches the product, is not a vendor root and no other installed application matches it.
- **Faster leftover scans:** ownership evidence is computed once per scan; a real scan dropped from
  about 116 to 27 seconds with identical results.
- **Self-relaunching uninstallers:** NSIS-style uninstallers that copy themselves and exit are now
  awaited while the application is still registered. Finished uninstalls are not held up by a
  lingering feedback page, and no process is ever terminated.
- **Unquoted uninstall commands:** `C:\Program Files\App\unins000.exe /S` resolves to the real
  executable; the longest existing path wins, so a planted `C:\Program.exe` is never chosen.
- **No duplicates:** per-user applications are listed once, and file associations / App Paths are
  no longer offered twice from the shared 32-bit registry view.
- **Quoted install locations** are recognized, so ownership and shortcut evidence apply.

Uncertain matches remain unselected for review. Every deletion is still backed up first and can be
restored from Backups.

  self-relaunch cases; junk detection with junction, locked, recent and changed-after-scan traps.
